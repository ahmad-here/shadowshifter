# Shadow Shift: SEO Implementation (Phases 1–2)

Implemented 2026-11-16, following `SEO_AUDIT.md`. No custom domain, no analytics (owner's choice).

## Done and verified (production build served statically)

- **Homepage:** H1 "Shadow Shift – Free 3D Parkour Game", a visible description and guide links that
  stay after the game loads (fixes the thin rendered page). Every clickable element has a real
  action; the made-up "Class S" and "Moves 8" were removed. Site-name signals: WebSite
  `name` + `alternateName`, `application-name`, `og:site_name`.
- **7 static pages** (generated by `npm run build:pages` from `tools/build-pages.mjs`):
  `/how-to-play/`, `/game-features/`, `/gameplay-tips/`, `/about/`, `/contact/`,
  `/privacy-policy/`, `/terms/`. Each returns 200, has a unique title and description, one H1,
  a self canonical, Open Graph/Twitter tags and valid BreadcrumbList JSON-LD. All internal links
  resolve (checked). Content describes only mechanics that exist in the code.
- **sitemap.xml:** 8 URLs, valid XML. **robots.txt** unchanged (allows all).
- **Favicons:** new icon; `favicon.ico` (16/32/48), 192/512 PNG, 180 apple-touch; manifest updated.
- **Service worker fix:** only the game page is stored as the offline copy (guide pages no
  longer overwrite it).
- Checks: typecheck, lint, 410 unit tests, production build and `check:prod` all pass.

# Website Architecture

Static site around the game, generated by `npm run build:pages` (`tools/build-pages.mjs` +
`tools/articles.mjs`) into `public/`. Plain HTML + `public/pages.css`: no Three.js, no JS, no
framework. Vite copies `public/` into `dist/`; the host serves real files (real 404s).

```
/                         game (React + Three.js), crawlable intro + links
├── /how-to-play/         start, controls, moves, obstacles, portals, restart, tips, FAQ
├── /game-features/       every feature, with screenshots
├── /gameplay-tips/       strategies
├── /blog/                listing, newest first
│   ├── /blog/beginners-guide-to-rooftop-parkour-games/
│   ├── /blog/improve-timing-in-endless-runner-games/
│   ├── /blog/parkour-movement-in-3d-games/
│   └── /blog/avoid-obstacles-in-running-games/
├── /about/
├── /contact/
├── /privacy-policy/
└── /terms/
```

**Shared layout:** header (brand; Home, How to Play, Features, Gameplay Tips, Blog, About; Play
now), breadcrumb nav, one H1, closing CTA, footer (brand, short description, About, How to Play,
Features, Gameplay Tips, Blog, Contact, Privacy Policy, Terms).

**Images:** `public/images/*.webp`, 1024×576, 12–29 KB, real gameplay captures. The first image on
a page uses `fetchpriority="high"`, the rest `loading="lazy"`; all have width/height (no CLS).

**Service worker:** caches only the game page as the offline copy.

**Adding an article:** append to `ARTICLES` in `tools/articles.mjs`, add an image, run
`npm run build:pages`. The sitemap, blog listing and related links update automatically.
